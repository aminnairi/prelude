# Contrbuting

Contributing guidelines for developers

> [!INFO]
> Common development knowledge is expected for helping developing this library, at least an understanding in the JavaScript language.

## Requirements

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/fr)
- [NPM](https://www.npmjs.com/)

## Clone

```bash
git clone https://github.com/aminnairi/prelude
cd prelude
```

## Lint

```bash
npm -w packages/prelude run lint
```

## Test

```bash
npm -w packages/prelude test
```
